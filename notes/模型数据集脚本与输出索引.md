更新日期：2026-10-29。覆盖四个已实现模型与原仓库十二个标准数据集，共 48 份脚本。独立 PULSE＋FACT 尚未实现；大桥数据不在本次范围。

脚本位于 `scripts/<ModelName>/<原数据集脚本名>.sh`，从 PULSE 工程根目录运行，使用原 `run.py`。原仓库根层脚本保持原样。每个脚本直接顺序执行下表中的四个预测长度，输入长度均为 96；沿用原版 PULSE 的顶部变量和四段命令，不定义 shell 函数或模型、时距选择器。需要单个时距时直接保留相应命令块。

## 运行方式

```bash
bash scripts/PULSE_SCF/electricity.sh
bash scripts/PULSE_SOFTS/ETTm2.sh
bash scripts/PULSE_SCF_SIMPLE/traffic.sh
bash scripts/PULSE/ETTh1.sh
bash scripts/PULSE_SCF/Weather.sh
bash scripts/PULSE_SCF/PEMS03.sh
```

每个模型目录固定自己的模型名。顶部 `experiment_id` 自动生成时间戳和进程号，只用于 `model_id` 和独立 checkpoint 实验目录，不进入日志路径。

## 一键执行三个扩展模型

[run_PULSE_SCF_SOFTS_SIMPLE.sh](../scripts/run_PULSE_SCF_SOFTS_SIMPLE.sh) 在 `scripts/` 下直接逐行调用现有数据集脚本，无函数、无并发，也不执行原 PULSE。运行命令：

```bash
bash scripts/run_PULSE_SCF_SOFTS_SIMPLE.sh
```

顺序为 PULSE_SCF 全部十二个数据集 → PULSE_SOFTS 全部十二个数据集 → PULSE_SCF_SIMPLE 全部十二个数据集。每个模型内的顺序为 ETTh1、ETTh2、ETTm1、ETTm2、electricity、traffic、Weather、Solar、PEMS03、PEMS04、PEMS07、PEMS08。共调用 36 份数据集脚本、执行 144 个训练命令，任一命令失败即停止；修复后可直接运行对应数据集脚本。启动清单不提供断点续跑或已完成跳过功能。

## 日志和 checkpoint 格式

日志文件名仅保留模型名及长度对，不追加数据集、时间戳、进程号：

```text
logs/<ModelName>/<dataset>/<ModelName>_<seq_len>_<pred_len>.log
checkpoints/<ModelName>/<setting>/checkpoint.pth
```

例如：

```text
logs/PULSE_SCF/ETTh1/PULSE_SCF_96_96.log
logs/PULSE_SCF/ETTh1/PULSE_SCF_96_192.log
logs/PULSE_SCF/weather/PULSE_SCF_96_336.log
logs/PULSE_SCF/PEMS03/PULSE_SCF_96_12.log
checkpoints/PULSE_SCF/<ETTh1_96_96_setting>/checkpoint.pth
```

保留模型和数据集分类，删除运行标识目录。不同长度各写一个日志；再次运行同一配置会覆盖固定路径的日志，需要保留时提前归档。终端直接打印日志绝对路径及 checkpoint 根目录；例如可另开终端执行 `tail -f logs/PULSE_SCF/ETTh1/PULSE_SCF_96_96.log` 查看训练进度。标准输出和错误均写入对应日志。

`setting` 沿用原入口生成的完整实验文件夹名，包含配置和独立运行标识。新增 `--checkpoints ./checkpoints/<ModelName>/` 是使用已有参数，不修改 `run.py`。原根层脚本、旧日志、旧 checkpoint 不自动迁移。

## 预计输出 tree

```text
PULSE-phy/
├── logs/
│   ├── PULSE/
│   ├── PULSE_SOFTS/
│   ├── PULSE_SCF_SIMPLE/
│   └── PULSE_SCF/
│       └── ETTh1/
│           ├── PULSE_SCF_96_96.log
│           ├── PULSE_SCF_96_192.log
│           ├── PULSE_SCF_96_336.log
│           └── PULSE_SCF_96_720.log
└── checkpoints/
    ├── PULSE/
    ├── PULSE_SOFTS/
    ├── PULSE_SCF_SIMPLE/
    └── PULSE_SCF/
        ├── <96_96_setting>/
        │   └── checkpoint.pth
        └── <96_192_setting>/
            └── checkpoint.pth
```

空白模型分支表示同样展开为相应数据集或实验目录。此为预计布局，不代表已经运行或生成了对应权重。

## 适用范围与检查

当前支持现有 `--is_training 1` 的训练、最佳权重恢复及随后自动测试。旧实验类独立 `--is_training 0` 分支的权重读取仍写死原根目录；若需要直接读取新分组 checkpoint，应另行适配并验证，当前不能把该分支视为已支持。

四十八份脚本的命令参数与原对应脚本逐项比较，仅模型名、独立模型标识及 checkpoint 根目录有预期差异。脚本验证不启动真实训练；另完成四模型 × 十二数据集配置 × 四时距共 192 项随机张量 CPU 前向检查，输出形状正确且数值有限。所有数据集的正式 GPU 结果仍需依据服务器真实训练日志。
