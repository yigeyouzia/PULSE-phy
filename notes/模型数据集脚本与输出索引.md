## 运行方式

```bash
bash scripts/PULSE_SCF/electricity.sh
bash scripts/PULSE_SOFTS/ETTm2.sh
bash scripts/PULSE_SCF_SIMPLE/traffic.sh
bash scripts/PULSE/ETTh1.sh
PRED_LENS="96 192" bash scripts/PULSE_SCF/Weather.sh
PRED_LENS="12 24" bash scripts/PULSE_SCF/PEMS03.sh
```

`PULSE_SCF/` 脚本保留 `MODEL_NAME` 选择的兼容用法，默认 PULSE_SCF；其他模型目录的脚本固定模型名。每次运行自动生成新的 `RUN_TAG`，也可手动指定未使用过的标识。

## 日志和 checkpoint 格式

日志文件名仅保留模型名及长度对，不追加数据集、时间戳、进程号：

```text
logs/<ModelName>/<dataset>/<run_tag>/<ModelName>_<seq_len>_<pred_len>.log
checkpoints/<ModelName>/<setting>/checkpoint.pth
```

例如：

```text
logs/PULSE_SCF/ETTh1/<run_tag>/PULSE_SCF_96_96.log
logs/PULSE_SCF/ETTh1/<run_tag>/PULSE_SCF_96_192.log
logs/PULSE_SCF/weather/<run_tag>/PULSE_SCF_96_336.log
logs/PULSE_SCF/PEMS03/<run_tag>/PULSE_SCF_96_12.log
checkpoints/PULSE_SCF/<ETTh1_96_96_setting>/checkpoint.pth
```

保留数据集与运行标识目录，防止十二个数据集的相同长度日志互相冲突。不同长度各写一个日志；终端会打印日志绝对路径、`tail -f` 命令及 checkpoint 根目录。

`setting` 沿用原入口生成的完整实验文件夹名，包含配置和独立运行标识。新增 `--checkpoints ./checkpoints/<ModelName>/` 是使用已有参数，不修改 `run.py`。原根层脚本、旧日志、旧 checkpoint 不自动迁移。

## 预计输出 tree

```text
PULSE-phy/
├── logs/
│   ├── PULSE/
│   ├── PULSE_SOFTS/
│   ├── PULSE_SCF_SIMPLE/
│   └── PULSE_SCF/
│       └── ETTh1/
│           └── <run_tag>/
│               ├── PULSE_SCF_96_96.log
│               ├── PULSE_SCF_96_192.log
│               ├── PULSE_SCF_96_336.log
│               └── PULSE_SCF_96_720.log
└── checkpoints/
    ├── PULSE/
    ├── PULSE_SOFTS/
    ├── PULSE_SCF_SIMPLE/
    └── PULSE_SCF/
        ├── <96_96_setting>/
        │   └── checkpoint.pth
        └── <96_192_setting>/
            └── checkpoint.pth
```

空白模型分支表示同样展开为相应数据集或实验目录。此为预计布局，不代表已经运行或生成了对应权重。

## 适用范围与检查

当前支持现有 `--is_training 1` 的训练、最佳权重恢复及随后自动测试。旧实验类独立 `--is_training 0` 分支的权重读取仍写死原根目录；若需要直接读取新分组 checkpoint，应另行适配并验证，当前不能把该分支视为已支持。

四十八份脚本的命令参数与原对应脚本逐项比较，仅模型名、独立模型标识及 checkpoint 根目录有预期差异。脚本验证不启动真实训练；另完成四模型 × 十二数据集配置 × 四时距共 192 项随机张量 CPU 前向检查，输出形状正确且数值有限。所有数据集的正式 GPU 结果仍需依据服务器真实训练日志。

完整约束和预计 tree 见 [AGENTS.md](../../AGENTS.md)，方法与结果见[开发计划](PULSE-SOFTS-FACT开发计划.md)。
