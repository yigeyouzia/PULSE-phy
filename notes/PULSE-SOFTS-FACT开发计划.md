## 1. 目标与当前决定

目标是围绕参考结构、变量共享背景与个体偏离之间的协作，形成有明确方法机制和实验依据的会议论文方案。阶段成功标准是整体预测效果接近选定的原主模型，允许略差；不要求全面超越三个来源模型。可接受差异范围在数据集、指标和比较协议确定后记录，不预设百分比。

| 项目 | 当前决定 |
| --- | --- |
| 整体承载框架 | PULSE |
| 内部预测 backbone | SOFTS 式变量嵌入、STAR、残差与 FFN、预测头，替换默认逐变量 MLP |
| 借用的补充机制 | FACT 的细粒度跨变量卷积块 |
| 拟研究的新连接 | 相对于共享核心构造表示偏离，由历史参考状态控制偏离交互修正 |
| 第一版范围 | 不接入完整 FACT 双域预测模型；不引入额外 ODE 求解器 |
| 训练流程 | 复用现有入口和实验流程，首轮采用非 AMP、单设备路径 |
| 训练入口改动 | `run.py` 保持原样；默认配置通过实验类中的最小模型注册接入，新增 CLI 参数仍须额外确认 |
| 主要比较参照 | 原 PULSE；补充 PULSE＋SOFTS 和简单连接以区分贡献 |
| 当前数据范围 | ETTh1、Weather；暂不安排 Gje 大桥数据内容 |

“共享背景与偏离的协作可以减少重复交互、适应状态变化”是研究假设，尚未由本项目实验验证。新颖性需要与最近邻工作比较，不能将普通门控或共性分解本身当作已成立的新贡献。

## 3. 拟实现结构与连接机制

```text
历史观测 X [B,L,C]
  ↓ PULSE：历史锚点 A、残差归一化与统计量
中间输入 X_in [B,L,C]
  ↓ SOFTS：变量嵌入
变量表示 Z [B,C,d]
  ├─ STAR：共享核心 c、共享更新 G
  └─ D = Z − Π(c) → FACT 卷积 → 偏离交互增量 ΔF
历史锚点、残差与统计量 → 状态条件 s → 门控 g(s)
  ↓ 合并 Z、G 与受控的 ΔF
SOFTS：LayerNorm、FFN 与预测头
  ↓ 中间预测 Y0 [B,H,C]
PULSE：未来锚点生成与尺度恢复
  ↓
最终预测 Y_hat [B,H,C]
```

拟采用的交互定义为：

$$
D=Z-\Pi(c),\qquad
\Delta F=F(D)-D,
$$

$$
Z_{\mathrm{merge}}=Z+G(Z,c)+g(s)\odot\Delta F.
$$

其中，`F` 表示完成轴适配后的 FACT 块。原块自带残差连接，因此接入时提取其增量，再与骨干的原表示和共享更新合并。合并后沿用 SOFTS 式归一化与 FFN。

`Π(c)` 是共享核心在变量表示空间中的映射，初版优先采用共享映射，避免直接增加大量变量专属参数。`D` 是相对于学习表示参照的偏离，不是 PULSE 的观测残差 `X−A`，也不自动是可识别物理量。

条件 `s` 拟由历史锚点编码、归一化残差编码、历史残差均值和标准差组成。门控的形状及粒度在接口阶段确定；首版优先考虑逐样本、逐变量的修正强度。门控使用历史可得信息，不输入未来观测值。

## 4. 接口与实现约束

- 新模型拟命名为 `PULSE_SCF`，类使用 `PULSESCFModel`，按工程惯例导出 `Model`；其他改造类使用明确的 `SCF` 前缀。
- 原 `PULSE.py` 保留。新模型复用参考处理和恢复能力，在新类中实现骨干替换与新增条件连接。
- 外部调用尽量兼容 `forward(x, cycle_index, batch_x_mark, batch_y_mark, do_mixup=True)`；训练返回 `(prediction, mixup_params)`，推理返回预测张量。
- 内部变量表示为 `[B,C,d]`；FACT 块接入时适配到 `[B,d,C]`，输出后恢复轴顺序。
- Backbone 输出 `Y0` 是 PULSE 恢复之前的中间预测，不能将最终观测尺度预测直接送入恢复流程。
- 整段归一化与逆变换统一由 PULSE 负责，不重复套用 SOFTS 或 FACT 的输入输出归一化；内部 LayerNorm、BatchNorm 单独分析。
- PULSE Router 维度与新骨干维度分别定义，避免共用 `d_model` 引起隐式变化。拟增加的骨干参数使用 `scf_` 前缀；命令行接入需先确认。
- SAM 沿用原训练配对，明确输入、门控条件、统计量与监督如何对应；不因接入新条件而默默改变原 Router、锚点或监督的混合规则。
- 保持 STAR 的训练、推理规则一致可追溯。若需要改变聚合方式，另建明确命名的实现，并作为独立设计变化记录。
- FACT 的变量布局是计算组织方式，不解释为真实空间拓扑；第一版不将其嵌入轴 FFT 当作物理频率使用。
- 需检查不同变量数下的补齐与裁剪、单变量边界以及配置合法性；来源实现若需修正，修正在新适配类中完成。
